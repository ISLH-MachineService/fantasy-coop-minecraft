# Fantasy Coop — Minecraft 1.21.1 NeoForge

Фэнтези-сборка для двоих: приключения, колония, магия, драконы + аниме-модели, катаны и эмоции.

## Скачать / установить

Нужны: **Java 21**, **Minecraft 1.21.1**, **NeoForge 21.1.x**, **Python 3**.

```bash
git clone https://github.com/ISLH-MachineService/fantasy-coop-minecraft.git
cd fantasy-coop-minecraft
python install.py
```

Или скачайте ZIP репозитория:

**https://github.com/ISLH-MachineService/fantasy-coop-minecraft/archive/refs/heads/main.zip**

Распакуйте и запустите `python install.py`.

Скрипт сам скачает моды, шейдеры и ресурс-паки в папки `mods/`, `shaderpacks/`, `resourcepacks/`.

Потом скопируйте эти три папки в инстанс:

- Prism / Modrinth App: папка инстанса 1.21.1 NeoForge
- Обычный лаунчер: `%appdata%\.minecraft`

RAM: **8–12 ГБ**. Оба игрока — одинаковый набор модов.

## Аниме-часть

- **Customizable Player Models** — аниме-модели персонажей
- **Emotecraft** — эмоции и позы
- **First Person Model** — видно своё тело от первого лица
- **Anime Weapons** — катаны Demon Slayer, One Piece, JJK
- **Better Katanas** — крафтовые катаны
- **Demon Slayer pack** — переименуй меч на наковальне

## Шейдеры

Complementary Reimagined (основной), Unbound, Bliss, BSL.
